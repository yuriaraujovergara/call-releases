# Toca — instaladores

Aqui ficam os instaladores do **Toca** para Windows.

**Para instalar:** abra a aba [Releases](https://github.com/yuriaraujovergara/call-releases/releases), baixe o `Toca-Setup-<versão>.exe` mais recente e execute.

Na primeira instalação o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Depois disso o Toca se atualiza sozinho.
